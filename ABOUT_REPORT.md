# About the Weekly Report

This document describes the data included in the weekly reports generated by the WeeklyReportApp and the logic used to filter and process the data.

## Overview

The application generates two report types:
1. **Stage Change Report** (`{date}_ステージ変更リスト.txt`)
2. **Weekly Sales Report** (`{date}_週刊レポート.txt`)

The current default workflow generates the weekly report, while the stage-change report remains available as an optional path that can be enabled in `main.py`.

## Data Source

- **Input Files**: Excel files from the `data/` folder, selected based on the latest available data.
- **Data Structure**: Each Excel file contains deal information with columns such as `ID`, `Company`, `Name`, `Stage`, `Size`, `Owner Fullname`, and stage-specific fields.
- **Processing**: Data is loaded and cleaned before report generation.

## Stage Mapping

Deals are grouped by Japanese stage labels using the following mapping:

```python
stage_map = {
    "5. Sales (Invoice)": "注文書受領",
    "4. S/O": "注文書受領",
    "3. Quotation": "見積り提出",
    "2. Proposal": "提案",
    "1-1. Potential (New Opportunity)": "新規案件",
    "1-2. Potential (Renewal)": "新規案件"
}
```

## Stage Change Report

### Purpose
This report highlights deals that changed stages or sizes between the two input files, plus new deals and upcoming renewals.

### Filtering Logic

1. **Stage Changes**: Deals where the stage changed between the old and new files.
2. **New Deals**: Deals present in the latest file but not in the previous one.
3. **Size Changes**: Deals where the `Size` field changed between files.
4. **Upcoming Renewals**: Renewal deals with effective dates in the current or next month.

### Output Format
- Grouped by Japanese stage labels.
- Each deal shows the company name, size, project name, owner name, and stage change information.

## Weekly Sales Report

### Purpose
This report provides a weekly overview of active sales pipeline items, including sales-owned deals and S/O-stage records.

### Filtering Logic

1. **Changed S/O Deals**: Deals in the `4. S/O` stage that changed.
2. **Sales-Owned Deals**: Deals owned by the sales team or otherwise included in the weekly view.
3. **Renewal Handling**: Renewal deals are included when they match the relevant timing rules.

### Output Format
- Grouped by Japanese stage labels.
- Each deal shows the company name, size, and project name.

## Row Formatting Details

Each deal row in the reports includes:

- **Company Name**: Cleaned company name.
- **Size**: Deal size displayed in a human-readable format.
- **Project Name**: Translated to Japanese using the translator service.
- **Stage-Specific Additions**: Additional text depending on the stage.
- **Stage Change Info**: Previous → current stage information, or a new-deal marker when applicable.

## Additional Processing

- **Translation**: Project names are translated to Japanese using `TranslatorService`.
- **Renewal Replacement**: The word `renewal` is replaced with `更新` before translation to keep the wording consistent.
- **Cleaning**: Company and project names are cleaned of special characters.
- **Output**: Reports are saved as UTF-8 encoded text files in the `output/` folder using the current date in the filename.
