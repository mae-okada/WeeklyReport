# 週刊レポート生成スクリプト

## 使い方
1. Python をインストールし、`py` コマンドが使える状態にします。
2. 依存パッケージを入れるために、**`install_dependencies.bat`** を実行します。
3. レポート生成には **`generate_report.bat`** を実行します。
4. 生成結果は **`output`** フォルダに保存されます。

## 依存関係
- 依存関係は **`requirements.txt`** と **`package.json`** で管理しています。
- 主要パッケージ:
  - `pandas`
  - `openpyxl`
  - `deep-translator`

## 生成されるレポート
- **`YYYYMMDD_週刊レポート.txt`**
- **`YYYYMMDD_ステージ変更リスト.txt`**

> 現在の実行フローでは、デフォルトで週刊レポートを生成します。ステージ変更リストの生成は [main.py](main.py) で有効化できます。

## 各レポートの定義

### 1. ステージ変更リスト
- **`data`** フォルダ内にある Excel ファイルのうち、最新の 2 つを比較します。
- `Stage` の変化やサイズ変更、新規案件、更新案件の対象を整理して出力します。

### 2. 週刊レポート
- 最新のデータをもとに、営業部向けの週次一覧を作成します。
- `4. S/O` の変更点や営業部所有のレコードを含めて出力します。

## 主要な処理
- Excel ファイルを読み込み、`pandas` で整形します。
- プロジェクト名は `TranslatorService` で日本語化します。
- 文字列中の `renewal` は、翻訳前にそのまま `更新` に置換されます。

## 各ステージの条件

- **1-1. Potential (New Opportunity)**
  新規案件

- **1-2. Potential (Renewal)**
  更新案件

- **2. Proposal**
  提案

- **3. Quotation**
  見積り提出

- **4. S/O**
  注文書受領

- **5. Sales (Invoice)**
  請求書送付済
